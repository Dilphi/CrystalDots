# 💎 Rhinofy — Генератор схем из страз

Rhinofy — это приложение для преобразования изображений в точечные схемы (в стиле выкладки страз).
Пользователь загружает фото, а программа автоматически генерирует схему с точками разного размера и считает количество страз.

---

## 🚀 Возможности

* 📷 Загрузка изображения
* ⚙️ Конвертация в точечный рисунок
* 💎 Поддержка разных размеров страз
* 📊 Подсчёт количества страз
* 👀 Предпросмотр (до/после)
* 💾 Сохранение результата в PNG
* 📈 Индикатор прогресса обработки

---

## 🧠 Как работает

1. Изображение переводится в оттенки серого
2. Делится на сетку (`GRID_SIZE`)
3. Для каждой ячейки вычисляется яркость
4. В зависимости от яркости выбирается размер страза
5. Генерируется новая картинка из точек

## ⚙️ Технологии

* Python
* Flet (UI)
* OpenCV (обработка изображений)
* Pillow (рисование)
* NumPy

---

## 📦 Установка

Убедись, что у тебя установлен Python 3.10+

```bash
pip install flet opencv-python pillow numpy
```

---

## ▶️ Запуск

```bash
python app.py
```

---

## 🛠️ Настройки

В коде можно менять параметры:

```python
GRID_SIZE = 10        # плотность точек
SIZES = [8, 10, 12, 15]  # размеры страз
THRESHOLDS = [60, 120, 180]  # пороги яркости
```
